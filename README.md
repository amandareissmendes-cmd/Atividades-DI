# Meu Portfólio Acadêmico

## Sobre o projeto

Este repositório reúne projetos desenvolvidos durante meus estudos na área de Tecnologia da Informação, com o objetivo de praticar programação, desenvolvimento web e organização de código.

O portfólio faz parte da minha trajetória acadêmica em Ciência da Computação e será atualizado conforme eu adquirir novos conhecimentos e desenvolver novos projetos.

## Projetos

### 1. Loja virtual com Bootstrap
Projeto de desenvolvimento de uma página web utilizando Bootstrap para estruturar e estilizar a interface.

**Tecnologias:** HTML, CSS, JavaScript e Bootstrap.

**Arquivos principais:**
- `index.html`
- `style.css`
- `script.js`

### 2. Loja virtual com CSS puro
Projeto desenvolvido para praticar a criação e a estilização de páginas web utilizando CSS, sem depender de frameworks de estilização.

**Tecnologias:** HTML, CSS e JavaScript.

### 3. Loja virtual com Tailwind CSS
Projeto de desenvolvimento web utilizando Tailwind CSS para construir e personalizar a interface.

**Tecnologias:** HTML, CSS, JavaScript e Tailwind CSS.

## Objetivos de aprendizagem

- Praticar HTML, CSS e JavaScript.
- Conhecer diferentes formas de estilizar interfaces web.
- Aprender a organizar e versionar projetos com Git e GitHub.
- Desenvolver páginas web com diferentes ferramentas.
- Construir um portfólio para acompanhar minha evolução acadêmica.
